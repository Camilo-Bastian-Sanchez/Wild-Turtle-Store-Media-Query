🐢 Wild Turtle Store
Tienda online de productos de Magic: The Gathering, desarrollada como parte del Desafío 3 del bootcamp de Desafío Latam. El proyecto consiste en una página web responsiva con dos layouts diferenciados: uno para dispositivos móviles y otro para escritorio.
📋 Descripción
Wild Turtle Store es una tienda de cartas y productos de Magic: The Gathering. La página permite visualizar el catálogo de productos, ordenarlos por distintos criterios y navegar entre páginas. El diseño se adapta automáticamente según el tamaño de la pantalla del usuario.

Mobile: navegación con menú hamburguesa, productos en una columna.
Tablet (576px+): barra lateral izquierda con navegación, productos en dos columnas.
Desktop (992px+): barra lateral izquierda con navegación, productos en cuatro columnas.

🛠️ Tecnologías utilizadas

HTML5 — estructura y semántica de la página
CSS3 — estilos y diseño visual

CSS Grid con grid-template-areas para los layouts
Flexbox para distribuir elementos dentro de cada sección
Media Queries para el diseño responsivo


JavaScript — interactividad del menú hamburguesa
Font Awesome — iconos de redes sociales en el footer
